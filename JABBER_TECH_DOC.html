01 — Product
What is Jabber?
Jabber is a real-time multilingual live-event translation platform. Event organisers connect their existing OBS/RTMP stream to Jabber and their audience can instantly listen in any of 10+ languages with sub-2-second latency — no interpreters, no hardware, no downloads.
🌐
Real-Time Translation
Audio translated and synthesised live with <2s end-to-end latency across 10+ languages.
🎙️
Works with Any Stream
Plug in any OBS or RTMP source. Setup takes under 10 minutes — no SDK needed.
👥
Viewer App Included
Attendees pick their language in-browser. No app download. Works on any device.
💰
Usage-Based Billing
$0 idle cost. Billed per minute of active streaming. Free $100 starter credits.
🔒
PII Redaction
Pro plan includes automatic personally-identifiable information filtering from transcripts.
📡
REST & WebSocket API
Full API access on Pro/Enterprise for custom integrations and white-label deployments.

09 — Workflow
How to Deploy Changes
Step-by-step to update and push the site.
1
Make your changes
Edit files in src/. The dev server runs with npm run dev (port 5173).
2
Test locally
Run npm run build to make sure there are no build errors before pushing.
3
Commit to GitHub
git add . && git commit -m "your message" && git push origin main
4
Deploy to Railway
railway up --service jabber --detach — builds and deploys in ~2 minutes. Or connect GitHub for auto-deploy on push.
5
Verify
Visit jabber.live and check Railway dashboard for "Online" status.
